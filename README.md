# 공연 모아보기 (KOPIS 실시간 연동)

공연예술통합전산망(KOPIS) 공연 정보를 그때그때 불러와 종류별, 예매처별로 보여 주는 앱이에요.

## 구조

- `public/index.html` : 화면 (브라우저에서 실행)
- `api/shows.js` : KOPIS를 대신 호출하는 서버리스 함수 (인증키는 여기서만 사용)
- `package.json` : Node 18 이상 지정

화면이 `/api/shows`를 부르고, 함수가 KOPIS에서 목록과 예매처 정보를 받아 돌려줘요.
인증키가 브라우저에 노출되지 않게 하려고 이렇게 나눴어요.

## 1단계. KOPIS 인증키 받기

1. KOPIS(kopis.or.kr)에 회원가입하고 로그인해요.
2. 오픈API 메뉴에서 이용 신청을 하고 서비스키를 발급받아요. 승인에 시간이 걸릴 수 있어요.
3. 같은 메뉴의 API 문서에서 아래를 꼭 확인하세요.
   - 공연 목록 조회의 요청 변수와 장르 코드 (`index.html`의 `CATS` 값과 맞는지)
   - 조회 기간 제한 (화면은 30일 단위로 조회해요)
   - 공연 상세 조회에 예매처 정보가 들어 있는지 (`relates`)
   - 하루 호출 한도

## 2단계. Vercel에 배포하기 (무료 플랜으로 시작 가능)

### 방법 A. 명령어로 배포

```bash
npm i -g vercel
cd show-board-app
vercel                      # 처음 실행하면 로그인과 프로젝트 설정을 물어요 (대부분 엔터)
vercel env add KOPIS_KEY    # 발급받은 서비스키 붙여넣기 (Production 선택)
vercel --prod               # 실제 주소로 배포
```

### 방법 B. GitHub로 배포

1. 이 폴더를 GitHub 저장소에 올려요. (인증키는 올리지 마세요)
2. vercel.com에서 저장소를 Import해요.
3. Settings > Environment Variables에 `KOPIS_KEY`를 추가해요.
4. Deploy를 누르면 끝이에요.

배포가 끝나면 `https://프로젝트이름.vercel.app` 주소가 생겨요. 휴대폰 홈 화면에 추가해 두면 편해요.

## 내 컴퓨터에서 먼저 테스트하기

```bash
cd show-board-app
echo "KOPIS_KEY=발급받은키" > .env.local
vercel dev
```

`http://localhost:3000` 에서 확인해요. `.env.local`은 GitHub에 올리지 마세요.

## 자주 만나는 문제

- 화면에 "KOPIS_KEY 환경변수가 설정되지 않았어요"가 나와요: 환경변수를 추가한 뒤 다시 배포해야 반영돼요.
- 목록이 비어 있어요: 장르 코드나 기간이 맞는지, 인증키가 승인되었는지 확인해요.
- 예매처 버튼이 안 나와요: 공연 상세 응답에 예매처 정보가 없는 경우예요. 호출량을 아끼려고 앞쪽 24개 공연만 상세 조회해요 (`api/shows.js`의 `DETAIL_LIMIT`).
- KOPIS 호출이 실패해요: `api/shows.js`의 `BASE` 주소 (`http`/`https`)를 KOPIS 문서와 맞춰 보세요. 환경변수 `KOPIS_BASE`로 바꿀 수 있어요.

## 알아 둘 점

- KOPIS는 공연 정보 서비스라서 예매 오픈일 같은 항목은 없을 수 있어요. 오픈일은 예매처 링크에서 확인하세요.
- 공연 목록·상세 응답은 10분 동안 캐시해서 호출량을 줄여요. 서버 메모리 캐시는 최대 500개까지만 두고, 상세 정보는 30분이 지나면 새로 받아요.
- 인증키는 `index.html`이나 GitHub에 절대 넣지 마세요.

## 찜 동기화 · 예매 오픈 알림 설정 (선택)

이 두 기능은 저장소와 키가 있어야 켜져요. 설정하지 않아도 나머지 기능은 그대로 쓸 수 있고,
화면에서 "서버에 ...가 설정되지 않았어요"라고 안내해요.

### 1. 저장소 연결 (찜 동기화에 필요)

1. Vercel 프로젝트 > Storage (또는 Marketplace)에서 **Upstash for Redis**를 추가하고 이 프로젝트에 연결해요. 무료 플랜으로 충분해요.
2. 연결하면 `KV_REST_API_URL`, `KV_REST_API_TOKEN` (또는 `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN`) 환경변수가 자동으로 생겨요.

동기화는 로그인 없이 12글자 코드(예: `K7QF-2MXP-9TZA`)로 해요. 찜 화면에서 "동기화 켜기"를 누르고,
다른 기기에서 코드를 입력하거나 "연결 링크 보내기"로 받은 링크를 열면 두 기기의 찜이 합쳐져요.
코드를 아는 사람은 누구나 그 찜 목록을 볼 수 있으니 가족끼리만 나눠 주세요. 400일 동안 쓰지 않으면 자동으로 지워져요.

### 2. 푸시 알림 키 (예매 오픈 알림에 필요, 저장소도 있어야 해요)

```bash
npx web-push generate-vapid-keys
```

나온 값을 Vercel 환경변수에 넣어요.

| 이름 | 값 |
|---|---|
| `VAPID_PUBLIC_KEY` | Public Key |
| `VAPID_PRIVATE_KEY` | Private Key (절대 공개하지 마세요) |
| `VAPID_SUBJECT` | `mailto:내이메일주소` |
| `CRON_SECRET` | 아무 긴 임의 문자열 (매일 알림 확인 작업 보호용) |

`vercel.json`에 매일 오전 9시(한국 시간)에 `/api/cron`을 부르도록 설정돼 있어요. 이때 알림을 켠 사람의 찜 공연을 확인해서

- 예매처가 없던 공연에 예매처가 생기면 "예매가 열렸어요"
- 공연이 7일 안에 끝나면 "곧 끝나는 공연이에요"

알림을 보내요. 같은 공연에 같은 알림은 한 번만 보내요.
푸시를 설정하지 않아도, 앱을 열 때 찜 공연 정보를 6시간마다 새로 받아서 예매가 열린 공연을 화면에 알려 줘요.

아이폰·아이패드는 Safari에서 "홈 화면에 추가"로 앱을 설치한 뒤, 설치된 앱 안에서만 알림을 켤 수 있어요 (iOS 16.4 이상).

## 앱으로 설치하기

- 안드로이드·PC 크롬/엣지: 화면 오른쪽 위 "📲 앱 설치" 버튼, 또는 주소창의 설치 아이콘
- 아이폰: Safari 공유 버튼 → "홈 화면에 추가"

설치하면 주소창 없이 앱처럼 열리고, 인터넷이 끊겨도 마지막으로 본 목록을 보여 줘요.

## 공유 링크

고른 구분·종류·기간·예산·검색어·보기 방식이 주소에 담겨요. "🔗 공유" 버튼으로 지금 화면을 그대로 보낼 수 있고,
공연 상세 화면의 "이 공연 공유"는 `/?show=공연ID` 링크를 보내요.

## 파일 구성 (추가된 것)

- `api/detail.js` : 공연 상세 (상세 보기, 찜 정보 새로 고침)
- `api/favs.js` : 찜 동기화
- `api/push.js` : 알림 구독
- `api/cron.js` : 매일 찜 공연 확인 후 알림 보내기
- `api/_lib/` : 함수들이 같이 쓰는 코드 (KOPIS 호출·캐시, 저장소, 푸시)
- `manifest.webmanifest`, `sw.js`, `icons/` : 앱 설치, 오프라인, 알림 받기
